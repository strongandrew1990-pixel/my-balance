# «Мой баланс»: первая версия

Подтверждено пользователем 02.10.2026. Пользователь прямо поручил перейти к реализации.

## Назначение
Личная сверка восьми жизненных сфер: оценки, короткие причины, изменения и 1–2 действия на весь следующий период.

## Сферы в установленном порядке
1. Отношения / семья
2. Финансы / инвестиции / деньги
3. Окружение / друзья / связи
4. Карьера / работа / бизнес
5. Здоровье
6. Саморазвитие / личностный рост
7. Быт / комфорт / материальные ценности
8. Хобби / путешествия

## Интерфейс
- Главная: последний обзор, восемь карточек, действия из предыдущего обзора и текущие действия, переход к новому обзору и истории.
- Новый обзор: дата, восемь обязательных оценок 1–10 без предвыбранной оценки на первом обзоре, необязательные короткие пояснения, изменения относительно предыдущего обзора по дате, общий вывод, одно или два непустых действия.
- История: обзоры по дате, полный просмотр каждого и отметки выполнения его действий. Сохранённые обзоры не редактируются в первой версии.
- Первый запуск пустой, без вымышленных данных. Светлый минималистичный адаптивный интерфейс, сдержанный зелёный акцент. Радарного графика нет.

## Данные и правила
HTML, CSS, JavaScript, localStorage. Без backend, базы данных, регистрации, облачной синхронизации и внешних зависимостей.
Один обзор на дату, будущие даты запрещены. Сравнение с ближайшим более ранним обзором; первый обзор не получает вымышленных изменений. Обзоры могут добавляться задним числом.
Модель обзора: id, date (YYYY-MM-DD), createdAt, scores (восемь ключей), reasons (восемь строк), conclusion, actions (1–2 объекта id/text/done).
Запись хранилища должна завершиться до обновления интерфейса. Ошибка чтения/формата не приводит к перезаписи старых данных. Ошибка сохранения оставляет форму открытой и введённые значения доступными. Пользовательский текст выводится как текст, без исполнения HTML.
При уходе из изменённой формы запрашивается подтверждение. Черновик сохраняется в памяти при переходах, до сохранения или явного отказа от него.

## Проверка
Проверить дату, диапазон оценок, 1–2 действия, сравнение по хронологии, дубликаты дат, ошибки localStorage, сохранение/перезагрузку, безопасный вывод текста, историю и мобильный размер.
